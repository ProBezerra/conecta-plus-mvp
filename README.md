# Conecta+ 🌐
> Plataforma de inclusão e alfabetização digital para comunidades vulneráveis e áreas com conectividade limitada.

## 📌 Sobre o Projeto
O **Conecta+** é uma solução tecnológica (web/mobile) desenvolvida para combater a desigualdade e a exclusão digital. A plataforma oferece treinamentos práticos de competências digitais, suporte offline-first para regiões com conexão instável e recursos para compartilhamento comunitário de dispositivos.

## 🚀 Funcionalidades do MVP
- 📚 Módulos de alfabetização digital básica e intermediária.
- 🔄 Arquitetura *offline-first* com sincronização automática de progresso.
- 📶 Mapeamento e gestão de pontos de conexão local.
- ♿ Acessibilidade alinhada às diretrizes WCAG 2.1 (alto contraste, navegação facilitada e suporte a leitores de tela).

## 🛠️ Tecnologias Utilizadas
- **Front-end:** React.js / React Native
- **Back-end:** Node.js
- **Banco de Dados:** PostgreSQL / MongoDB (com suporte local via PouchDB/IndexedDB)
- **Versionamento & CI/CD:** GitHub, GitHub Actions
